# Archive

Deprecated or superseded files, and inbox notes that have been fully integrated into the core buckets.

The vault is additive: content is archived rather than deleted, so its history stays easy to find. The index builder does not scan this folder, so archived notes never show up in `search-kb` results.

When you archive a note, update any wiki-links that pointed at its old location.
